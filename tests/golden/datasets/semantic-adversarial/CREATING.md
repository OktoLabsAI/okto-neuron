# Semantic adversarial dataset

This is a fictional, commit-safe ADR 0040 fixture. It was authored to exercise the live semantic
pipeline, not merely the offline evaluator:

- same-person aliases;
- an exact namesake split across `Agent` and `Place`;
- one surface with `InformationObject` and `Concept` senses;
- all five closed primitives;
- a relation stated in inverse surface order;
- literal-versus-topology classification;
- structural mention noise and unsupported inference;
- Unicode-preserving alias discovery; and
- a useful novel predicate that should remain governed as provisional unless mapped.

The questions and source spans are an automated draft. Deterministic provenance preflight is
allowed before owner review. Human adjudication, threshold locking, and ADR 0040 acceptance are not.
