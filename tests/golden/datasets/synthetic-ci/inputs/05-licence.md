# Brackish Open Data Licence (BODL)

The Tidewater Index is published under the Brackish Open Data Licence, known by
the short code BODL.

- **BODL v1** - effective 2020-06-15. Required attribution to the Halverson
  Tidewater Collective but did not allow commercial redistribution.
- **BODL v2** - effective 2022-04-22. Adds an explicit commercial-use permission
  and a share-alike clause. BODL v2 supersedes BODL v1.

Under BODL v2, any republished dataset must credit "Halverson Tidewater
Collective" and carry the same licence. The licence is maintained by the
Community Trust program, coordinated by Tomas Larsen.

The current licence covering the Tidewater Index is BODL v2. There is no BODL v3.

Grants that fund licence compliance work are administered by Hana Vesely.
